Finding a route through Wikipedia

Can an LLM find its way through Wikipedia using only article links?

A paper newly listed on arXiv today tests navigation across five Wikipedia languages and five research-literature graphs. Model rankings change with language and topic.

The human comparison is small: nine players and 109 English games, with a 10-minute limit. Models had a 100-step limit. The model set includes GPT-4o and o3-mini.

Useful evaluation idea: score the route a retrieval system takes.

Include the setup with the result

Two people saying 'I tried AI' can mean very different setups.

Include the model, date, tools and actual task when sharing a result. A run transcript gives the next person something they can inspect.

Karpathy's audience estimates here are rough guesses.

Diagrams you can inspect and edit

Diagram Design gives an AI agent a concrete output format: a single HTML file with SVG diagrams.

You can inspect the labels and relationships, then edit the file. Review those connections before spending time on the colours.
