## 📖 About This Repository

---

This folder contains a static export of my creator portfolio for YoursTrulyHQ. The live site is hosted separately and is available at the link above. The export keeps the page, styles, interactions and artwork together for review or local browsing.

<br>

## 🚀 Key Implementations

---

* Instagram visual stories with their public reel links and displayed view counts.
* A dated audience snapshot from Instagram Insights and YouTube Studio.
* Selected YouTube videos, including a VAE deep learning explainer.
* Contact details for creative collaborations and brand partnerships.

The figures in `metrics.json` were checked on 31 October 2026. Instagram uses its last 30 days window and YouTube uses 1–30 October 2026. This is a dated snapshot, not a live analytics feed. Current follower and subscriber totals are labelled separately from period growth.
